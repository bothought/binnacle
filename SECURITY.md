# Security Policy

Binnacle can execute host commands. Please treat security reports as sensitive.

- **Do not open a public issue for a vulnerability.**
- Use GitHub Security Advisories: https://github.com/bothought/binnacle/security/advisories/new
- Include the affected version, deployment mode (forward/local), reproduction
  steps, and impact.

Read the threat model and hardening checklist in [docs/security.md](docs/security.md).

The maintainer aims to acknowledge reports within a few days. There is no bug
bounty.
